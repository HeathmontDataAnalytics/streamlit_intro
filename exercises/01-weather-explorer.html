The Geography department wants a simple web app for exploring a year of weather in four Australian cities. You'll build it with Streamlit, a Python library that turns a script into an interactive web page.

In this exercise you will:

  • write your first Streamlit app
  • read a CSV file into a pandas DataFrame (a table of data)
  • explore it: its size, its columns and its summary statistics
  • sort and filter it to answer questions

The data, data/weather.csv, has one row per city per day for 2025: 1,460 rows. It is simulated: it follows each city's typical climate but isn't a real weather record.

How it works: write code in the middle panel and press Run (or Ctrl+Enter). Your app appears on the right. Each step has a hint and a description of what you should see, so you can check your own work.

A Streamlit app is just a Python script. Streamlit runs it from top to bottom, and every st. command adds something to the page.

The editor already contains a tiny app. Press Run to see it.

Lines that start with # are comments. Python ignores them: they're notes for people reading the code, including you next week. A good comment sits above a section of code and says what that section does, in a few plain words:

# A big title, then a line of text

To work with tables of data we use pandas. By tradition it's imported with the short name pd. pd.read_csv() reads a CSV file into a DataFrame, which we'll store in a variable called df.

  1. Under import streamlit as st, add import pandas as pd.
  2. At the bottom, read the file: df = pd.read_csv("data/weather.csv")
  3. Add a subheader that says The data, then show the table with st.dataframe(df).

Your code should end like this:

# Load the weather data from the CSV file
df = pd.read_csv("data/weather.csv")

# Show the whole table

st.dataframe(df)

Before using a dataset, a data scientist checks its size, its column names and its typical values. pandas makes each of these one line:

  • df.shape gives the number of rows and the number of columns
  • df.columns.tolist() gives a list of the column names
  • df.describe() gives summary statistics (count, mean, min, max…) for each number column
  1. Store the size in two variables: rows, columns = df.shape
  2. Show them with st.write("Rows:", rows) and a similar line for columns.
  3. Show the column names with st.write("Column names:", df.columns.tolist()).
  4. Add a subheader Summary statistics and show df.describe() with st.dataframe.

st.write can take several things separated by commas and shows them side by side.

# How big is the table, and what are its columns?
rows, columns = df.shape
st.write("Rows:", rows)
st.write("Columns:", columns)

Which days were the hottest? df.sort_values("max_temp", ascending=False) sorts the table by max_temp from highest to lowest, and .head(10) keeps the first 10 rows. You can chain them together on one line.

To keep only some rows, put a condition inside square brackets:

melbourne = df[df["city"] == "Melbourne"]

Read it as: keep the rows of df where the city column equals "Melbourne". Note the double equals sign ==, which compares two values.

A column has handy methods such as .mean(), .max() and .sum(). st.metric shows a single number in large type.

  1. Make a DataFrame melbourne with only Melbourne's rows.
  2. Add a subheader Melbourne.
  3. Show the average maximum temperature, rounded to 1 decimal place:
    st.metric("Average max temp (°C)", round(melbourne["max_temp"].mean(), 1))
  4. Add a second metric for the total rainfall in mm (use .sum()).
  5. Challenge: change the city to Sydney, Brisbane or Perth. What do you have to change?
# Keep only Melbourne's rows and summarise them
melbourne = df[df["city"] == "Melbourne"]

st.subheader("Melbourne")
st.metric("Average max temp (°C)", round(melbourne["max_temp"].mean(), 1))
st.metric("Total rain (mm)", round(melbourne["rain_mm"].sum(), 1))

City names start with a capital letter, exactly as in the data: "Melbourne", not "melbourne".

Two big numbers under Melbourne: an average maximum temperature of about 19.4 °C and a total rainfall of about 605 mm.

Doing that once for each city would be slow. groupby does it for every city at once: it splits the table into one group per city and works out a value for each group.

df.groupby("city")["rain_mm"].sum()

Read it as: group the rows by city, take the rain_mm column, and add it up for each group.

  1. Add a subheader All four cities.
  2. Make a table of the average of the four number columns for each city, rounded to 1 decimal place, and show it: 
    averages = df.groupby("city")[["max_temp", "min_temp", "rain_mm", "sunshine_hours"]].mean().round(1)
    (The double square brackets pick several columns at once.)
  3. Work out each city's total rain with .sum() and store it in total_rain.
  4. Find the wettest city with total_rain.idxmax(), which gives the name with the biggest value, and show it with st.write.
# Average each column for every city at once
st.subheader("All four cities")
averages = df.groupby("city")[["max_temp", "min_temp", "rain_mm", "sunshine_hours"]].mean().round(1)
st.dataframe(averages)

# Total rain for each city, then the wettest one
total_rain = df.groupby("city")["rain_mm"].sum()
st.write("The wettest city was", total_rain.idxmax())

A table with one row for each city (Brisbane, Melbourne, Perth, Sydney) and the average of each column. Brisbane has the highest average maximum temperature.

Then the sentence The wettest city was Sydney.
