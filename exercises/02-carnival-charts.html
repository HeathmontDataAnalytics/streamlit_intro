Ridgeview College (a made-up school) has just held its athletics carnival. The results are in an Excel spreadsheet, and the sports department wants charts for the school newsletter. You'll build an app that makes them.

In this exercise you will:

  • read an Excel file into a DataFrame
  • add up results with groupby
  • draw bar charts, scatter plots and box plots with Plotly Express
  • give charts titles, labels and the house colours
  • organise the app into tabs

The data, data/athletics.xlsx, has one row for each competitor in each final: 288 rows. Each final has 8 runners or jumpers, 2 from each house (Banksia, Grevillea, Waratah and Wattle). 1st place earns 10 points, 2nd earns 8, down to 1 point for 8th. All names are made up.

This exercise assumes you've done exercise 1, or know how pd.read_csv, st.dataframe and filtering with df[df["column"] == value] work. As in exercise 1, add a short # comment above each new section of code you write.

Which house is winning? First add up each house's points with groupby:

house_points = df.groupby("house")["points"].sum().reset_index()

.reset_index() turns the result back into an ordinary table with two columns, house and points. That's the shape Plotly likes.

Plotly Express (imported as px) makes a chart in one line. You say which table to use and which columns go on the x and y axes. st.plotly_chart() puts the chart on the page.

  1. Add import plotly.express as px to the imports at the top.
  2. Add a subheader Points by house.
  3. Make house_points as above and show it with st.dataframe.
  4. Make a bar chart: fig = px.bar(house_points, x="house", y="points"), then show it with st.plotly_chart(fig).

Remember:

  • Plotly Express is imported with import plotly.express as px.
  • groupby() takes the column to group by. The column to add up goes in square brackets after it.
  • px.bar() takes the table first, then x= and y= with column names in quotes.
  • A Plotly chart goes on the page with st.plotly_chart().

A chart for the newsletter needs a title, readable axis labels and the right colours. Plotly functions take extra keyword arguments for each of these, like title="...".

Each house has a colour. A Python dictionary stores pairs like these. The house name is the key and its colour is the value:

house_colours = {
    "Banksia": "orange",
    "Grevillea": "royalblue",
    "Waratah": "crimson",
    "Wattle": "gold",
}
  1. Sort house_points so the winning house comes first: add .sort_values("points", ascending=False) to the end of the line that makes it.
  2. Add the house_colours dictionary near the top of your code, after df is read.
  3. Change your px.bar(...) call so it also has:
    • color="house" and color_discrete_map=house_colours
    • title="Total points by house"
    • labels={"house": "House", "points": "Points"} to tidy the axis labels
    • text="points" to write the value on each bar

Remember:

  • The keyword names you need are color=, color_discrete_map=, title=, labels= and text=. Plotly spells it color, the American way.
  • labels= takes a dictionary: {"column": "Nice label"}.
  • sort_values(..., ascending=False) from exercise 1 puts the biggest first.
  • A long function call can go over several lines, with a comma after each argument.

The app is getting long. Tabs let readers pick one section at a time. st.tabs takes a list of tab names and gives back one tab for each:

tab1, tab2 = st.tabs(["Houses", "Year levels"])

with tab1:
    st.plotly_chart(fig)

Everything indented under with tab1: appears inside that tab. Python uses 4 spaces for each level of indentation.
