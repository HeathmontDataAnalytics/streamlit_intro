Ridgeview College (a made-up school) has just held its athletics carnival. The results are in an Excel spreadsheet, and the sports department wants charts for the school newsletter. You'll build an app that makes them.

In this exercise you will:

  • read an Excel file into a DataFrame
  • add up results with groupby
  • draw bar charts, scatter plots and box plots with Plotly Express
  • give charts titles, labels and the house colours
  • organise the app into tabs

The data, data/athletics.xlsx, has one row for each competitor in each final: 288 rows. Each final has 8 runners or jumpers, 2 from each house (Banksia, Grevillea, Waratah and Wattle). 1st place earns 10 points, 2nd earns 8, down to 1 point for 8th. All names are made up.

This exercise assumes you've done exercise 1, or know how pd.read_csv, st.dataframe and filtering with df[df["column"] == value] work. As in exercise 1, add a short # comment above each new section of code you write.

Reading Excel works just like reading CSV: use pd.read_excel() instead of pd.read_csv(). (On your own computer, this needs the openpyxl package, which is already installed on this page.)

  1. Read data/athletics.xlsx into a DataFrame called df.
  2. Show how many results there are with st.write("Results recorded:", len(df)). len(df) is the number of rows.
  3. Show the table with st.dataframe(df, hide_index=True).
# Load the carnival results from the Excel file
df = pd.read_excel("data/athletics.xlsx")
st.write("Results recorded:", len(df))
st.dataframe(df, hide_index=True)

Results recorded: 288 and a table with the columns event, event_type, year_level, competitor, house, result, unit, place and points.

The first row is Ivy A. from Banksia, who won the Year 7 100m in 14.52 seconds.

Which house is winning? First add up each house's points with groupby:

house_points = df.groupby("house")["points"].sum().reset_index()

.reset_index() turns the result back into an ordinary table with two columns, house and points. That's the shape Plotly likes.

Plotly Express (imported as px) makes a chart in one line. You say which table to use and which columns go on the x and y axes. st.plotly_chart() puts the chart on the page.

  1. Add import plotly.express as px to the imports at the top.
  2. Add a subheader Points by house.
  3. Make house_points as above and show it with st.dataframe.
  4. Make a bar chart: fig = px.bar(house_points, x="house", y="points"), then show it with st.plotly_chart(fig).
# Add up the points for each house
st.subheader("Points by house")
house_points = df.groupby("house")["points"].sum().reset_index()
st.dataframe(house_points, hide_index=True)

# Bar chart of total points, one bar per house
fig = px.bar(house_points, x="house", y="points")
st.plotly_chart(fig)

Check that you added the import plotly.express as px line, or Python won't know what px is.

A small table with 4 rows, then a bar chart with 4 bars. Banksia is winning with 413 points, then Grevillea (384), Waratah (321) and Wattle (286).

Hover over a bar to see its exact value. Plotly charts also let you zoom: drag across the chart, then double-click to zoom back out.

A chart for the newsletter needs a title, readable axis labels and the right colours. Plotly functions take extra keyword arguments for each of these, like title="...".

Each house has a colour. A Python dictionary stores pairs like these. The house name is the key and its colour is the value:

house_colours = {
    "Banksia": "orange",
    "Grevillea": "royalblue",
    "Waratah": "crimson",
    "Wattle": "gold",
}
  1. Sort house_points so the winning house comes first: add .sort_values("points", ascending=False) to the end of the line that makes it.
  2. Add the house_colours dictionary near the top of your code, after df is read.
  3. Change your px.bar(...) call so it also has:
    • color="house" and color_discrete_map=house_colours
    • title="Total points by house"
    • labels={"house": "House", "points": "Points"} to tidy the axis labels
    • text="points" to write the value on each bar

Long function calls can be split over several lines. Put a comma after each argument:

# Bar chart of total points, one bar per house
fig = px.bar(
    house_points,
    x="house",
    y="points",
    color="house",
    color_discrete_map=house_colours,
    title="Total points by house",
    labels={"house": "House", "points": "Points"},
    text="points",
)
st.plotly_chart(fig)

Plotly spells it color, the American way. The dictionary name is up to you; we used house_colours.

The bars are now in order (Banksia, Grevillea, Waratah, Wattle), each in its house colour, with the points written on the bar. The chart has the title Total points by house and the axes say House and Points.

Is Banksia strong in every year level? You can group by two columns at once by passing a list:

year_points = df.groupby(["year_level", "house"])["points"].sum().reset_index()

That gives one row for each year level and house: 6 × 4 = 24 rows.

  1. Add a subheader Points by year level and make year_points as above.
  2. Draw a bar chart with x="year_level", y="points" and color="house". Use your house_colours again, and add a title and labels. Store it in a new variable, fig2.
  3. Add barmode="group" so the houses' bars sit side by side.
  4. Try it: remove barmode="group" and run again. What changes? Which version is better for comparing houses?
# Grouped bars: one bar per house in each year level
fig2 = px.bar(
    year_points,
    x="year_level",
    y="points",
    color="house",
    barmode="group",
    color_discrete_map=house_colours,
    title="Points by year level",
    labels={"year_level": "Year level", "points": "Points", "house": "House"},
)
st.plotly_chart(fig2)

Six groups of four coloured bars, one group for each of Years 7 to 12. Banksia wins most year levels, but Waratah wins Year 10 and Grevillea wins Year 12.

Without barmode="group", the bars are stacked on top of each other, which shows each year level's total.

Points only tell part of the story. Let's look at actual times in the 100m. First keep only the 100m rows, then draw a scatter plot: one dot per runner.

hover_name="competitor" shows the runner's name when you hover over a dot.

  1. Add a subheader 100m sprint.
  2. Make sprint, a DataFrame with only the rows where event is "100m".
  3. Draw fig3, a scatter plot of sprint with x="year_level", y="result", color="house" and hover_name="competitor". Use the house colours, a title and labels (the result is a time in seconds).
  4. Challenge: make fig4, a box plot of the same data with px.box(sprint, x="year_level", y="result"). It shows the spread of times in each year level.
# Keep only the 100m results
sprint = df[df["event"] == "100m"]

# One dot per runner; hover to see their name
fig3 = px.scatter(
    sprint,
    x="year_level",
    y="result",
    color="house",
    hover_name="competitor",
    color_discrete_map=house_colours,
    title="100m times by year level",
    labels={"year_level": "Year level", "result": "Time (seconds)", "house": "House"},
)
st.plotly_chart(fig3)

The box plot needs only the table, x and y, but you can add a title and labels too.

A scatter plot with 8 dots above each year level. The dots get lower (faster times) for older students: the Year 7 times are around 14.5 to 15.5 seconds and the fastest Year 12 time is about 12.5 seconds.

In the box plot, each box covers the middle half of the times, with the median as a line across it.

The app is getting long. Tabs let readers pick one section at a time. st.tabs takes a list of tab names and gives back one tab for each:

tab1, tab2 = st.tabs(["Houses", "Year levels"])

with tab1:
    st.plotly_chart(fig)

Everything indented under with tab1: appears inside that tab. Python uses 4 spaces for each level of indentation.

  1. Create the four figures first, without showing them.
  2. Make four tabs: Houses, Year levels, 100m and Data.
  3. Put each chart in its tab with with, and the full results table (st.dataframe(df)) in the Data tab.
  4. Remove the old subheaders and st.plotly_chart lines so nothing appears twice.

Keep all the code that makes fig, fig2, fig3 and fig4. Then, at the end:

# One tab for each chart, and one for the data
tab1, tab2, tab3, tab4 = st.tabs(["Houses", "Year levels", "100m", "Data"])

with tab1:
    st.plotly_chart(fig)

with tab2:
    st.plotly_chart(fig2)

with tab3:
    st.plotly_chart(fig3)
    st.plotly_chart(fig4)

with tab4:
    st.dataframe(df, hide_index=True)
