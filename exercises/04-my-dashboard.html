Time to put it all together. Your apps so far worked with one dataset that was written into the code. This dashboard works with any CSV or Excel file: the user uploads a file, and the app shows its size, a table, a summary and a chart they can configure.

In this exercise you will:

  • let the user upload a file with st.file_uploader
  • handle both CSV and Excel files
  • build chart controls from the file's own column names
  • organise everything with a sidebar and tabs

Uploaded files stay inside your browser: nothing is sent to a server. Keep files small (under about 5 MB) so your device doesn't run out of memory.

st.file_uploader draws an upload box. Until the user has uploaded something it gives back None, a special value that means "nothing".

If there's no file yet, there's nothing for the rest of the app to show. Show a message, then stop the script with st.stop().

pandas can read the uploaded file directly: pd.read_csv(uploaded).

  1. Add an uploader that accepts CSV files: uploaded = st.file_uploader("Choose a CSV file", type=["csv"])
  2. If uploaded is None, show st.info("Upload a file to get started.") and call st.stop().
  3. Otherwise read it into df, show the file's name (uploaded.name) and show the table.
  4. Run the app and upload weather.csv.

Remember:

  • st.file_uploader() takes a label and type=, a list of file endings.
  • Check for "nothing" with is None.
  • st.info() shows a blue message and st.stop() ends the script there.
  • pd.read_csv() can read the uploaded file directly, and uploaded.name is its file name.

You don't know in advance which columns the file will have, so build the chart controls from the file itself:

  • df.columns.tolist() lists every column, which suits the x axis.
  • df.select_dtypes("number").columns.tolist() lists only the number columns, which suits the y axis.

Two more controls make the chart much more useful:

  • Colour by a column, so each city (or house, or type) gets its own colour and its own line. The first option, (none), means no colour.
  • Average the y values for each x value. For example, the average max_temp for each month.

Averaging makes a new, smaller table with just two columns, so there's nothing left to colour by. In that case, set the colour back to None.

  1. Add a Colour by selectbox with ["(none)"] + df.columns.tolist() as its options. Set colour to None if the choice is "(none)", and to the chosen column otherwise.
  2. Add a checkbox Average the y values for each x value.
  3. Make plot_df = df. If the box is ticked, replace it with the averages and set colour to None.
  4. Use plot_df and color=colour in all three chart functions, and add an f-string title.

Remember:

  • Two lists join with +, so ["(none)"] + df.columns.tolist() puts (none) first.
  • None (no quotes) means "nothing". Giving Plotly color=None means no colour.
  • groupby(...)[...].mean().reset_index() works like the groupby in exercise 2, but with the variables x_col and y_col instead of column names in quotes.
  • Add color= and title= to each of the three chart functions.
