How this site works

  • Everything runs in your browser. Python, pandas, Plotly and Streamlit run inside the web page (using Pyodide and stlite). There's nothing to install and no account.
  • Nothing is uploaded. Your code, and any file you open in exercise 4, stays on your device.
  • The first load is slow. Python takes 30 seconds or more to download the first time; after that your browser keeps a copy and it's quicker. Read the introduction while you wait.
  • Your progress is saved in this browser. Your code and ticked-off steps are kept on this device for next time. Clearing your browser data, or using a private window, removes them. Each exercise has a Reset progress link.
  • Check your own work. Answers aren't marked automatically. Each step has a hint and a description of what you should see. If you get stuck, Load the starting code for this step lets you carry on.
  • Keep your apps. Download .py saves your code as a normal Streamlit file. To run it on your own computer, install the packages with pip install streamlit pandas plotly openpyxl, then run streamlit run followed by the file name. The data files are on the last step of each exercise.

The weather and athletics data are simulated, and all the names in them are made up. The Pokémon data is Pokemon Stats by Ulrik Thyge Pedersen, licensed under CC BY 4.0, with a few corrections.
